# 富芮坤 FR802x、FR803x 型号能力表

核对基线为 MoteFrame `3331950`，日期为 2026-11-27。目录划分见[多厂商硬件适配架构](../../../docs/architecture/hardware-support.md)。

下表来自厂商《富芮坤 FR802X 简介》（2025-12）第 6 页选型表。表内七种料号均列出 8 Mbit Flash、2 路 I²C、2 路 SPI、1 路 I²S 和 BLE 5.3。RAM 按厂商 KB 口径，PSRAM 单列；外设数量是芯片资源，同时可用的组合取决于封装引脚复用。

| 型号 | 封装 | 主频 MHz | RAM KB / PSRAM MB | GPIO / UART | CAN | 型号证据与 Rust 板测 |
|---|---|---:|---|---|---|---|
| FR8022D | QFN32 | 96 | 64 / 无 | 18 / 3 | 无 | 选型表；待移植 |
| FR8023D | QFN48 | 96 | 64 / 无 | 34 / 4 | 无 | 选型表；待移植 |
| FR8026D | QFN32 | 144 | 96 / 无 | 18 / 3 | 1 | 另有 QFN32 参考设计；待移植 |
| FR8028D | QFN48 | 144 | 96 / 无 | 34 / 4 | 1 | 另有 EVB 手册与原理图；待移植 |
| FR8028DP | QFN48 | 144 | 96 / 2 | 34 / 4 | 1 | 选型表及屏显应用表；待移植 |
| FR8029D | QFN68 | 144 | 96 / 无 | 42 / 4 | 1 | FR8029D 固件目标已有板测，见[开发板实测状态](../../boards/fr8029d-evb/README.md)；实物封装后缀待核 |
| FR8029DP | QFN68 | 144 | 96 / 2 | 42 / 4 | 1 | 有开发板资料；本项目未单独验收 DP 或 PSRAM |
| FR8029DM | QFN68 | 待核 | 待核 | 待核 | 待核 | 有独立 QFN68 参考设计 V1.3；缺逐项选型数据及板测 |
| FR803x（具体料号待核） | 待核 | 待核 | 待核 | 待核 | 待核 | 联合参考手册 V1.5 覆盖该系列，本次取得的资料缺少 FR803x 分型号选型表、封装引脚表和板测记录 |

FR803x 移植的首个输入是具体订货料号、对应规格书及目标板原理图。依次核对 Flash/RAM 和启动入口、引脚与调试口、时钟中断、总线实例、无线控制器与 ROM 接口，逐项标记可复用或需新后端。仅凭联合手册中的寄存器章节，无法判断某一封装是否引出了该外设。

## 系列驱动与板测范围

| 层级 | 当前代码 | 依据及验证范围 |
|---|---|---|
| FR802x 系列 | [`fr802x-common`](fr802x/common/src/lib.rs) 的 TIMER0、PMU 字节访问、GPIO 和 TouchKey 扫描 | 联合参考手册 V1.5 和 SDK v0.3.6 的 FR802x 寄存器定义。FR8029D EVB 已完成自动板测，其他型号接入时需核对时钟、中断、封装引脚和对应寄存器。 |
| FR8029D 型号 | [`fr8029d-chip`](fr802x/fr8029d/src/lib.rs) 的射频、SARADC、QSPI | 射频校准、基带描述符、接收时序和 P25Q80 的约束沿用 FR8029D 实测配置。 |
| FR803x 系列 | 型号能力资料 | 具体订货料号与板测仍待补齐。 |
