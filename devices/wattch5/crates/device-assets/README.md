# device-assets

安全 no_std 无堆的只读素材基础层，与芯片、屏幕型号、产品页面无关。

- `ReadAt`：带容量的精确偏移读取，失败后输出必须丢弃。
- `Region`：先检查范围、溢出和当前源容量，再发生I/O。
- `Memory`：不可变内存源，供主机及映射资源适配使用。
- `ReadOnlyNor`：embedded-hal1 SpiDevice 适配，只发AB唤醒、9F标识、03读取；
  没有写使能、编程、擦除、状态写或复位入口。单次最多256字节。
- `Bitmap`：RGB565 BE/LE或本地16色高半字节优先的紧密像素流，
  每次最多解码128个同行像素，使用固定256字节临时缓冲。

调用方在每次读事务/图像跨度之间服务其他任务。不要在CS有效期间让出总线。
容量由常规JEDEC密度编码推导，不是独立的硅片容量测量；未知编码明确拒绝。
具体厂商8字节素材头解析放在产品示例的适配器，不进入这个通用crate。

LCD和Flash共享SPI时可使用 `device-core::spi::SharedBus`，它在完整事务期间
保持独占、等待flush并释放CS，失败后锁定总线等待硬件恢复。
芯片MISO、模式与速度设置仍由板级适配负责。
