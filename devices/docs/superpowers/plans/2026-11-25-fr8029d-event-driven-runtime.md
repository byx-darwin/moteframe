# 裸机与 FreeRTOS 共用事件驱动运行时里程碑

目标是在设备工程内复用 BLE、UI、传感器和存储逻辑，由设备固件在构建时选择裸机或 FreeRTOS。两种构建共用板级事件来源和有界工作步骤。裸机入口在空闲时等待中断，FreeRTOS 入口用任务通知等待。MoteFrame 的公开接口保持兼容。

FR8029D 是首个 BLE 实机目标。现有裸机和 FreeRTOS GATT 样例作为对照。Mac CoreBluetooth 负责广播发现、连接、订阅、带响应写入和对照通知，J-Link 负责板上计数和栈水位。早期集成从 SRAM 运行并在测试结束后复位回原厂固件。Flash 执行版的镜像和 SRAM 预留按 ELF 统计，冷启动验收单独记录。

## 1. Mac BLE 验收基线

- [x] 在 `scripts/ble_connect.swift` 增加 FR8029D 裸机和 FreeRTOS 探针选择，保留原 `RUST-LINK` 入口与其协议。
- [x] Mac 脚本按探针名和 GATT UUID 确认识别。两版都在首次订阅后写入 `FR29NT75`，重连并重新订阅后写入 `FR29RC02`。写入确认和匹配回显均收到才判定该轮通过。日志按阶段记录故障。
- [ ] 从 SRAM 分别运行 `FR29-GAT2` 和 `FR29-RTOS`，完成 Mac 连接、带响应写入、Notify 和重连后复测。首次实机验收停在扫描阶段。J-Link 确认两版进入广播阶段，并在试验结束后复位到原厂应用，核对了 Flash 前 12 KiB。手机历史记录保留为对照。

## 2. FR8029D 共用硬件唤醒

- [x] 在 `firmware/fr8029d-bringup` 的 `ble-gatt-event-driven` 候选构建接入基带 IRQ0 和 TIMER0。ISR 记录唤醒，BLE 所有者串行推进控制器和读取基带状态。
- [x] 主机测试覆盖最早截止时间、粗细计数换算与回绕、轮询期间的唤醒标志，以及缺少完成事件时的超时截止时间。
- [x] 裸机接入 WFI，FreeRTOS 接入任务通知。交叉编译和打包时核对两路中断向量、诊断区及镜像和栈的边界。
- [ ] 实机验证基带和定时器中断、等待前后的竞态及缺失 IRQ 时的超时，记录 `WAKE_STATS`、连接窗口最小余量和栈水位。
