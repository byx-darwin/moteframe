## 实施顺序与验收

1. **资料和实物对版（M1）**。本次资料整理完成现有资料、实现和板测记录的对照。下一次接触实物时补录丝印、PCB 版本、跳线和屏幕装件；取得 FR803x 具体型号资料后增加独立行。
2. **建立 FR8029D 基线**。固定裸机和 FreeRTOS 镜像及功能开关，各记录 Flash、静态 RAM、栈预留和压力场景实测水位；每次提取驱动复跑 BLE 重连、写入和 Notify。
3. **跑通采集产品路径**。选定传感器和接线，验证定时采集、缓冲、BLE 上报、延后保存及总线故障恢复。记录同时采集与 BLE 活跃时的丢样和栈余量。
4. **逐组验收整板**。按上表补触摸、显示、音频、USB、CAN 和低功耗。每项关联实物板型、固件配置、外接设备、观测结果；互斥引脚组合分别测试。
5. **验证第二型号**。优先选有完整资料和样板的 FR803x，从启动、调试和一条采集链开始，再验证射频、存储和 OTA。以两块板的记录确定系列共用驱动边界。

项目实现可从[固件入口](../../firmware/fr8029d-bringup/src/main.rs)、[射频后端](../../firmware/fr8029d-bringup/src/gatt_board_radio.rs)、[配置接入](../../firmware/fr8029d-bringup/src/qspi_config.rs)、[Flash 布局](../../firmware/fr8029d-bringup/src/flash_layout.rs)和 [OTA 实现](../../firmware/fr8029d-bringup/src/ota.rs)核对。厂商 SDK v0.3.6 示例只作为硬件行为参考。
